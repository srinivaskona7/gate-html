Module 2 · Linear Algebra

The study of linear transformations — operations that stretch, rotate, project and shear space without bending straight lines. A matrix is just a table of numbers that encodes such a transformation. Hold that sentence and most of this module becomes geometry rather than memorisation.

2.1 Matrices

A matrix is a rectangular array with m rows and n columns. Three equally valid readings, all useful:

  1. A table of data — the bookkeeping view.
  2. A system of equations in compact form — the algebraic view.
  3. A function that transforms vectors — the geometric view, and the one that explains everything else.

Multiplication

cij = Σk aik bkj

The inner dimensions must match and they vanish; the outer dimensions survive. Row i of A is dotted with column j of B.

Three facts that cost marks. AB ≠ BA in general. AB = 0 does not imply A = 0 or B = 0. And both (AB)ᵀ = BᵀAᵀ and (AB)⁻¹ = B⁻¹A⁻¹ reverse the order.

Special matrices

NameDefining condition
SymmetricAᵀ = A
Skew-symmetricAᵀ = −A (forces a zero diagonal)
OrthogonalAᵀA = I, so A⁻¹ = Aᵀ; det = ±1
IdempotentA² = A (a projection)
NilpotentAᵏ = 0 for some k
InvolutoryA² = I
Singulardet(A) = 0 — no inverse

Rank

Vectors are linearly independent if the only combination giving zero is the all-zero one. The rank is the number of independent rows — equivalently columns, since row rank always equals column rank.

Compute it by row-reducing to echelon form and counting non-zero rows. The three elementary row operations — swap, scale by a non-zero constant, add a multiple of another row — never change the rank.

2.2 Determinants

The determinant is a single scalar. Geometrically, its absolute value is the factor by which the matrix scales area or volume, and its sign records whether orientation flipped.

Why det = 0 matters. It means the transformation squashes space into a lower dimension — information is destroyed, so nothing can undo it. That one idea explains the whole chain: det = 0 ⟺ singular ⟺ rows dependent ⟺ rank < n ⟺ Ax = 0 has non-trivial solutions.

Properties that save time

#Property
1det(Aᵀ) = det(A)
2Swapping two rows flips the sign
3det(kA) = kⁿ det(A) for order n
4Adding a multiple of one row to another changes nothing — the workhorse
5Identical, proportional or zero row ⟹ det = 0
6Triangular ⟹ det = product of the diagonal
7det(AB) = det(A)det(B); det(A⁻¹) = 1/det(A)
8det(A) = Πλᵢ and tr(A) = Σλᵢ
PROBLEM 2.1 · 1 mark

Compute the determinant of 211132100

Show solution

Expand along row 3 — it has two zeros, so there is only one term to compute:

det = 1·(−1)3+1·(1·2 − 1·3) = 1·(−1) = −1

(Machine-verified by full recursive cofactor expansion.) Since det ≠ 0, the matrix is non-singular with rank 3. Always expand along the row or column with the most zeros. ∎

2.3 Systems of Linear Equations

The complete consistency rule

Let r = rank(A), rₐ = rank of the augmented matrix, with n unknowns.

ConditionOutcome
r ≠ rₐInconsistent — no solution
r = rₐ = nUnique solution
r = rₐ < nInfinitely many, with n − r free parameters

A homogeneous system always has rₐ = r, so it is never inconsistent. For a square homogeneous system, non-trivial solutions exist iff det(A) = 0.

PROBLEM 2.2 · 2 marks

For what k does this system have no solution?

x + y + z = 3  ·  x + 2y + 3z = 4  ·  x + 4y + kz = 6

Show solution

After R₂ − R₁, R₃ − R₁, then R₃ − 3R₂, the last row reads (k − 7)z = 0.

  • k ≠ 7: z = 0, unique solution.
  • k = 7: the row becomes 0 = 0, so r = rₐ = 2 < 3 ⟹ infinitely many.

The answer is that no value of k makes it inconsistent. The augmented entry is 0 in every case, so rₐ can never exceed r. Assuming a parameter must produce inconsistency is trap #8 on the master list and a recurring GATE device. ∎

2.4 Eigenvalues and Eigenvectors

Most vectors get knocked off their line when a matrix acts on them. A few special vectors do not — they are only stretched or shrunk, staying on their own span. Those are the eigenvectors, and the stretch factor is the eigenvalue.

Av = λv, v ≠ 0

For a non-zero v to exist, (A − λI) must be singular:

det(A − λI) = 0

For 2×2 there is a shortcut worth memorising: λ² − tr(A)·λ + det(A) = 0.

Properties — high frequency in GATE

  • Σλᵢ = tr(A) and Πλᵢ = det(A) — instant sanity checks.
  • A is singular ⟺ 0 is an eigenvalue.
  • Triangular or diagonal ⟹ eigenvalues are the diagonal entries.
  • A and Aᵀ share eigenvalues.
  • Eigenvalues of Aᵏ are λᵏ; of A⁻¹ are 1/λ; of A + cI are λ + c — eigenvectors unchanged in all three.
  • Real symmetric ⟹ real eigenvalues, orthogonal eigenvectors.
  • Always 1 ≤ GM ≤ AM. Diagonalisable ⟺ GM = AM for every eigenvalue.
  • Cayley–Hamilton: every matrix satisfies its own characteristic equation.
PROBLEM 2.3 · 2 marks

Find the eigenvalues and eigenvectors of 4123

Show full solution

Step 1 — characteristic equation. tr = 7, det = 12 − 2 = 10:

λ² − 7λ + 10 = 0 → (λ−5)(λ−2) = 0 → λ = 5, 2

Checks: 5 + 2 = 7 = tr ✓ and 5 × 2 = 10 = det ✓ (machine-verified).

Step 2 — eigenvector for λ = 5. B − 5I = [[−1,1],[2,−2]]. Row 1 gives v₁ = v₂, so take v = (1, 1)ᵀ. Check: Bv = (5, 5)ᵀ = 5v ✓

Step 3 — eigenvector for λ = 2. B − 2I = [[2,1],[2,1]]. Row 1 gives v₂ = −2v₁, so take v = (1, −2)ᵀ. Check: Bv = (2, −4)ᵀ = 2v ✓

Distinct eigenvalues ⟹ independent eigenvectors ⟹ B is diagonalisable with P = [[1,1],[1,−2]] and D = diag(5, 2). ∎

2.5 LU Decomposition

Gaussian elimination costs about ⅔n³ operations. If you must solve Ax = b for many different b with the same A — the normal engineering situation — repeating that work is wasteful. LU factors A once, then handles each new b in only O(n²).

Ax = b → LUx = b → Ly = b (forward), then Ux = y (back)

Doolittle puts 1s on L's diagonal; Crout puts them on U's. Default to Doolittle. Bonus: det(A) = Πuᵢᵢ, the product of U's pivots.

PROBLEM 2.5 · 2 marks

Find the LU decomposition of 2−1−2−463−4−28 and solve Ax = (−6, 17, 16)ᵀ.

Show full solution

Step 1 — eliminate column 1. Multipliers m₂₁ = −4/2 = −2, m₃₁ = −2. Rows become [0, 4, −1] and [0, −4, 4].

Step 2 — eliminate column 2. m₃₂ = −4/4 = −1, giving [0, 0, 3].

Step 3 — assemble. L = 100−210−2−11 U = 2−1−204−1003 (verified: LU = A exactly, in rational arithmetic)

Step 4 — forward substitution. y₁ = −6; then 12 + y₂ = 17 → y₂ = 5; then 12 − 5 + y₃ = 16 → y₃ = 9.

Step 5 — back substitution. 3x₃ = 9 → x₃ = 3; 4x₂ − 3 = 5 → x₂ = 2; 2x₁ − 2 − 6 = −6 → x₁ = 1.

x = (1, 2, 3)ᵀ

Also det(A) = 2 × 4 × 3 = 24. (All machine-verified.) ∎
