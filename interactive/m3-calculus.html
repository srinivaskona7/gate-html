Module 3 · Calculus

The mathematics of change (differential) and accumulation (integral). The Fundamental Theorem reveals these two to be inverse operations — arguably the single most important fact in the subject.

3.1 Limits

limx→a f(x) = L means we can force f(x) as close to L as we like by taking x close enough to a — without ever setting x = a. The value f(a) is irrelevant to the limit; it may differ, or not exist at all.

The ε–δ definition as a game. You name a tolerance ε around L. I must supply a window δ around a that keeps the whole curve inside your tolerance. If I can always answer, the limit exists.

Existence: the limit exists iff the left-hand and right-hand limits both exist and are equal.

▶ Diagram D3.1 · The tolerance game

Shrink ε and watch a narrower δ keep the curve trapped inside the band.

Techniques, in the order you should try them

  1. Direct substitution — if f is continuous at a, you are done.
  2. Factor and cancel for 0/0.
  3. Rationalise when roots appear.
  4. Standard limits (memorise): sin x / x → 1, tan x / x → 1, (1−cos x)/x² → ½, (eˣ−1)/x → 1, ln(1+x)/x → 1, (1+x)1/x → e.
  5. L'Hôpital's rule — only for 0/0 and ∞/∞.
  6. Squeeze theorem — for oscillating functions.
  7. Taylor expansion — often faster than repeated L'Hôpital.
Trap #11. Applying L'Hôpital to a determinate form such as 1/0 produces nonsense. Other indeterminates (0·∞, ∞−∞, 1∞) must first be rearranged into 0/0 or ∞/∞.

Continuity and differentiability

f is continuous at a iff three things hold: f(a) is defined, the limit exists, and they are equal. Informally — you can draw through a without lifting your pen.

f′(a) = limh→0 [ f(a+h) − f(a) ] / h

The one-way implication (trap #9). Differentiable ⟹ continuous. The converse is false. |x| is continuous everywhere but not differentiable at 0, because the left derivative is −1 and the right is +1. Corners, cusps, vertical tangents and jumps all destroy differentiability.

PROBLEM 3.1 · 1 mark

Evaluate limx→0 (√(1+x) − 1) / x

Show solution

Method A — rationalise. Multiply by the conjugate:

[(1+x) − 1] / [x(√(1+x)+1)] = 1 / (√(1+x)+1) → 1/2

Method B — L'Hôpital. The form is 0/0; differentiating gives 1/(2√(1+x)) → 1/2.

Answer: ½. Numerically confirmed: 0.49988 at x = 10⁻³, 0.4999999 at x = 10⁻⁶. ∎

PROBLEM 3.2 · 2 marks

Find a, b making f(x) = x² for x ≤ 1 and ax + b for x > 1 differentiable at x = 1.

Show solution

Continuity first: left value 1, right limit a + b, so a + b = 1.

Then differentiability: left derivative 2, right derivative a, so a = 2.

Hence a = 2, b = −1. Continuity is a prerequisite — solving only the derivative condition is the classic error here. ∎

3.2 Maxima, Minima and the Mean Value Theorem

A critical point is where f′ = 0 or f′ fails to exist. Extrema occur only at critical points or interval endpoints.

TestConditionConclusion
First derivativef′ changes + → −local maximum
First derivativef′ changes − → +local minimum
Second derivativef″(c) > 0local minimum (concave up)
Second derivativef″(c) < 0local maximum (concave down)
Second derivativef″(c) = 0inconclusive — fall back to the first test
Trap #10. For absolute extrema on [a,b], evaluate f at every critical point and at both endpoints. Forgetting the endpoints is the most commonly lost mark in this topic.

▶ Diagram D3.4 · The three-graph stack

The best study aid in this module. Dashed guides show that f′ crosses zero exactly where f peaks or troughs, and f″ crosses zero exactly at f's inflection.

Mean value theorems

Rolle: if f is continuous on [a,b], differentiable on (a,b), and f(a) = f(b), then some c has f′(c) = 0. Return to the same height and you must have levelled off somewhere.

Lagrange (LMVT): drop the equal-endpoints condition; then some c satisfies

f′(c) = [ f(b) − f(a) ] / (b − a)

At some instant your speedometer read exactly your average speed.

▶ Diagram D3.5 · MVT — tangent parallel to chord

Drag the interval. The red tangent at c is always parallel to the blue chord.

Every hypothesis matters. |x| on [−1,1] satisfies f(−1) = f(1) yet has no point with f′ = 0, because differentiability fails at 0. GATE loves exactly this counterexample.
PROBLEM 3.3 · 2 marks

Classify the local extrema of f(x) = x³ − 3x + 2, then find the absolute extrema on [−2, 2].

Show full solution

Step 1 — critical points. f′ = 3x² − 3 = 0 → x = ±1.

Step 2 — classify with f″ = 6x. f″(−1) = −6 < 0 → local maximum, f(−1) = 4. f″(1) = 6 > 0 → local minimum, f(1) = 0.

Step 3 — endpoints. f(−2) = 0 and f(2) = 4.

Step 4 — compare the whole list {0, 4, 0, 4} (all four machine-verified).

Absolute maximum = 4, at both x = −1 and x = 2. Absolute minimum = 0, at both x = −2 and x = 1. Inflection at x = 0. ∎

3.3 Integration

Two apparently unrelated definitions turn out to be one.

  • Indefinite integral: the antiderivative, ∫f dx = F(x) + C. The +C exists because differentiation destroys constants.
  • Definite integral: signed area, defined as a limit of rectangle sums. Area below the axis counts as negative.
Fundamental Theorem of Calculus. Part 1: d/dx ∫ax f(t)dt = f(x) — accumulate then differentiate and you are back where you started. Part 2: ∫ab f = F(b) − F(a) — this is what makes integration tractable at all.

Integration by parts and ILATE

∫ u dv = uv − ∫ v du

Choose u by ILATE — Inverse trig, Logarithmic, Algebraic, Trigonometric, Exponential — taking whichever appears earliest, because it simplifies on differentiation.

The symmetry shortcut

Over a symmetric interval [−a, a]: an even function gives 2∫₀ᵃ f; an odd function gives 0. Spotting an odd integrand reduces a hard integral to one line.

PROBLEMS 3.5 – 3.8 · mixed

3.5 ∫₀¹ x²eˣ dx  ·  3.6 ∫₀π sin²x dx  ·  3.7 ∫₁e ln x dx  ·  3.8 ∫₋₂² (x³ + x cos x) dx

Show all solutions

3.5 By ILATE take u = x². First pass gives e − 2∫₀¹xeˣdx; the inner integral is e − (e−1) = 1. So the answer is e − 2 ≈ 0.71828. Simpson's rule gives 0.7182818284590556 against e−2 = 0.7182818284590451 — agreement to 13 significant digits.

3.6 Use sin²x = (1 − cos2x)/2, giving ½[x − sin2x/2]₀π = π/2 ≈ 1.5708. Simpson confirms 1.5707963267948966. Sanity check: sin² averages ½ over a full period, and ½ × π = π/2 ✓

3.7 By ILATE take u = ln x, giving [x ln x]₁e − [x]₁e = e − (e−1) = 1. Simpson: 0.9999999999999947.

3.8 Both terms are odd — (−x)³ = −x³ and (−x)cos(−x) = −x cos x since cos is even. The interval is symmetric, so the answer is 0 with no antiderivative needed. ∎
