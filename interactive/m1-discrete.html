Module 1 · Discrete Mathematics

The mathematics of separate, countable things — statements that are true or false, elements in a set, nodes in a network. The highest-yield GATE topic, because computers are themselves discrete machines.

1.1 Propositional Logic

A proposition is a declarative sentence that is definitely either true or false — never both, never neither.

  • “7 is a prime number.” → a proposition (true).
  • “Delhi is the capital of France.” → a proposition (false).
  • “What time is it?” → not a proposition; a question has no truth value.
  • “x > 5” → not a proposition until x is fixed. This is a predicate.

The five connectives, defined completely

The one row everyone gets wrong. p → q is true whenever p is false. “If the moon is made of cheese, then I am the king” is a true statement — a promise whose condition never occurs is never broken. This is vacuous truth. Memorise: an implication is false in exactly one situation — true premise, false conclusion.

PROBLEM 1.1 · 1 mark

Show that [(p→q) ∧ (q→r)] → (p→r) is a tautology.

Show full solution

Method A — truth table. Run the sweep above. All eight rows evaluate to T, so the formula is a tautology. (Verified by exhaustive machine check.)

Method B — the exam-speed route. Assume the whole formula is false. Then LHS = T and p→r = F. From p→r = F we get p=T and r=F. From LHS, p→q=T with p=T forces q=T. But then q→r = T→F = F, so LHS = F — a contradiction. No falsifying row exists, therefore it is a tautology. ∎

1.2 First-Order (Predicate) Logic

“Every student passed” and “Some student passed” are different claims, yet propositional logic can only call each a single opaque letter. First-order logic looks inside the sentence.

  • Predicate: a statement with slots — P(x) = “x is prime”. P(7) is T; P(8) is F.
  • Domain: the set variables range over. Always state it — truth depends on it.
  • Quantifiers: ∀x P(x) (“for every x”); ∃x P(x) (“for at least one x”).

The two translation templates

EnglishCorrect logicWhy the alternative fails
“All A are B”∀x (A(x) → B(x)) Using ∧ would claim everything in the universe is both an A and a B.
“Some A is B”∃x (A(x) ∧ B(x)) Using → would be satisfied vacuously by any non-A object — a free pass.
Pattern: ∀ pairs with → ; ∃ pairs with ∧.

Negation — quantifier duality

¬∀x P(x) ≡ ∃x ¬P(x)      ¬∃x P(x) ≡ ∀x ¬P(x)

To negate: push the ¬ inward, flipping every quantifier as it passes, and negate the body. “Not everyone is happy” = “someone is unhappy”.

PROBLEM 1.6 · 2 marks

Over the integers with S(x,y) meaning x + y = 0, which is true? (a) ∀x∃y S(x,y)   (b) ∃y∀x S(x,y)

Show full solution

(a) True. Given any integer x, choose y = −x; then x + y = 0. ✓

(b) False. It claims one fixed y works for every x. Take that y; it fails for x = 1 − y, since (1−y) + y = 1 ≠ 0. ✗

Moral: the inner variable may depend on the outer one, never the reverse. ∎

1.3 Sets, Relations, Functions

A set is an unordered collection of distinct objects. Order and repetition are irrelevant: {1,2,2,3} = {3,1,2}. Note ∅ ≠ {∅} — the second is a box containing an empty box, so it has cardinality 1.

If |A| = n then the power set has 2ⁿ elements, because building a subset means making n independent in/out decisions.

Inclusion–Exclusion Principle

|A ∪ B| = |A| + |B| − |A ∩ B|

|A∪B∪C| = |A|+|B|+|C| − |A∩B| − |A∩C| − |B∩C| + |A∩B∩C|

Add singles, subtract pairs, add triples — alternating.

Antisymmetric is not the negation of symmetric. A relation can be both (equality) or neither. This is trap #4 on the master list.

1.4 Partial Orders and Lattices

A poset is a set with a relation that is reflexive, antisymmetric and transitive. “Partial” means some pairs may be incomparable. A lattice is a poset where every pair has both a join (least upper bound, ∨) and a meet (greatest lower bound, ∧).

In a divisibility poset, join = LCM and meet = GCD.

PROBLEM 1.11 · 2 marks

For D₃₆: find lub(4,6) and glb(4,6). Is it a lattice? A Boolean algebra?

Show full solution

Divisors: {1, 2, 3, 4, 6, 9, 12, 18, 36} — 9 elements (machine-enumerated).

lub(4,6) = lcm(4,6) = 12.   glb(4,6) = gcd(4,6) = 2.

Since LCM and GCD exist for every pair and stay inside the set, D₃₆ is a lattice, bounded with bottom 1 and top 36. It is distributive (Dₙ always is).

Not complemented: for a = 6 we need a′ with lcm = 36 and gcd = 1; the only candidate coprime to 6 is 1, whose lcm with 6 is 6, not 36. So it is not a Boolean algebra. General rule: Dₙ is Boolean iff n is square-free, and 36 = 2²·3² is not. ∎

Lagrange's theorem: for a finite group, the order of any subgroup divides the order of the group. Corollary: a group of prime order is cyclic with no proper subgroups.

PROBLEM 1.13 · 2 marks

For (ℤ₁₂, +): find all generators, the order of 8, and verify Lagrange.

Show full solution

Generators are the a with gcd(a,12) = 1: {1, 5, 7, 11} — that is φ(12) = 4 of them (machine-enumerated).

Lagrange: ⟨8⟩ = {0, 4, 8} has order 3, and 3 divides 12 ✓ ∎

1.6 Graph Theory

A graph is a set of vertices plus edges joining pairs. Write n = |V|, m = |E|.

Handshaking lemma. The sum of all degrees equals 2m, because each edge contributes two ends. Corollary: the number of odd-degree vertices is always even.

Euler vs Hamilton — the contrast that gets tested

Euler circuitHamiltonian cycle
Visits every…edge exactly oncevertex exactly once

Matching and colouring

  • Maximal matching cannot be extended; maximum matching is the largest overall. These differ.
  • Berge's theorem: a matching is maximum iff no augmenting path exists.
  • Hall's theorem: a matching saturating X exists iff |N(S)| ≥ |S| for every S ⊆ X.
  • König: in bipartite graphs, max matching = min vertex cover.
  • Chromatic number: trees and bipartite graphs 2; odd cycles 3; Kₙ is n; any planar graph ≤ 4.
  • Vizing: edge chromatic number is either Δ or Δ+1 — only two possibilities, always.

Solving a linear recurrence

  1. Write the characteristic equation.
  2. Distinct roots → aₙ = α r₁ⁿ + β r₂ⁿ.
  3. Repeated root → aₙ = (α + βn) rⁿ.
  4. Substitute the initial conditions and solve for α, β.
